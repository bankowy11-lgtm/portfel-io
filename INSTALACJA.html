📱 Instalacja Portfel.io na Androida

Masz 3 opcje — od najprostszej do najbardziej zaawansowanej.

Metoda 1 — NAJŁATWIEJSZA GitHub Pages + Chrome install

  1. Załóż darmowe konto na github.com
  2. Nowe repozytorium → wgraj pliki z tej paczki ZIP
  3. Settings → Pages → Source: main branch → Save
  4. Twoja aplikacja działa pod adresem https://TWOJA_NAZWA.github.io/REPO/
  5. Na Androidzie otwórz ten URL w Chrome
  6. Chrome automatycznie zaproponuje "Zainstaluj aplikację" (lub: menu ⋮ → Dodaj do ekranu głównego → pojawi się jako osobna apka)
✅ Bezpłatne, nie wymaga żadnych uprawnień, działa jak natywna apka (własna ikona, brak paska przeglądarki, splash screen)

Metoda 2 — BEZ SERWERA PWABuilder → APK

  1. Wgraj pliki na GitHub Pages (jak wyżej) lub dowolny hosting (np. Netlify)
  2. Wejdź na pwabuilder.com
  3. Wklej URL swojej strony → kliknij Start
  4. Wybierz Android → Generate Package
  5. Pobierz plik .apk
  6. Na telefonie: Ustawienia → Bezpieczeństwo → Instalacja z nieznanych źródeł → włącz
  7. Zainstaluj pobrany APK
✅ Prawdziwy APK w szufladzie aplikacji. Darmowe. PWABuilder generuje tzw. TWA (Trusted Web Activity).

Metoda 3 — ZAAWANSOWANA Buysub.dev / Capacitor

  1. Zainstaluj Node.js
  2. Uruchom: npm install -g @capacitor/cli
  3. Skonwertuj projekt: npx cap init
  4. Zbuduj APK w Android Studio
⚠️ Wymaga wiedzy technicznej i Android Studio (~8GB). Polecane tylko jeśli chcesz wrzucić na Google Play.

📦 Co zawiera ta paczka ZIP

  • index.html — główna aplikacja (PWA-ready)
  • manifest.json — konfiguracja PWA (ikona, nazwa, kolory)
  • sw.js — Service Worker (cache, tryb offline)
  • icons/ — ikony we wszystkich rozmiarach (72–512px)
  • INSTALACJA.html — ten plik
